# Предпросмотр серии статей «Права тракториста» — avtoklass-perm.ru

Отдельный статический хаб для просмотра готовой серии из 30 статей целиком
и отчёта о ней. Это не боевой сайт и не публикация на нём — только
просмотр. Все страницы закрыты от поисковиков (`robots: noindex, nofollow`):
тексты должны впервые попасть в поиск на avtoklass-perm.ru, в день выхода
по расписанию.

На боевом сайте статьи выходят сами, по одной раз в два дня, — см.
`site/docs/blog-publishing.md` в основном проекте.

## Структура

- `scripts/` — исходный код сборки:
  - `build_site.js` — сборщик. Читает очередь публикации
    (`../site/blog/queue.json`) и черновики (`../content-strategy/drafts/`),
    отрезает служебные блоки, переводит markdown в HTML тем же конвертером,
    что и боевой сайт (`../site/scripts/blog-bundle.js`). Ссылки на статьи
    серии становятся ссылками внутри хаба, остальные (страницы автошколы) —
    абсолютными ссылками на avtoklass-perm.ru. У каждой статьи указаны дата
    и адрес выхода на сайте. Страница отчёта собирается из
    `../content-strategy/report_content.md`; коды статей (A2, B10) в нём
    заменяются заголовками со ссылками.
  - `style.css` — типографика и вёрстка.
  - `check_site.py` — проверка собранного хаба: битые ссылки и картинки,
    утечки служебных блоков, видимые коды статей, наличие `noindex`, утечки
    файлов конвейера (`strategy.json`, `pipeline.json`), полнота набора статей.
- `docs/` — собранный сайт (GitHub Pages читает именно эту папку).

## Пересборка

```bash
node preview/scripts/build_site.js      # из корня проекта avto-klass
python3 preview/scripts/check_site.py
```

Зависимостей нет: Node 18+ и Python 3.

## Локальный просмотр

```bash
cd preview/docs && python3 -m http.server 8123
```
